# AccidentVision AI: Road Accident Detection using CNN & EfficientNetB0

##  Project Overview

AccidentVision AI is a Deep Learning and Computer Vision project designed to detect road accidents from images. The project explores both a custom 
Convolutional Neural Network (CNN) and Transfer Learning using EfficientNetB0 to classify images as Accident or Non-Accident.

The objective is to demonstrate how AI can assist intelligent transportation systems by automating accident detection and enabling faster response mechanisms.

## Dataset
The model was trained on a labeled road accident image dataset containing accident and non-accident images.

## Models Implemented

### 1. Custom CNN

A Convolutional Neural Network was built from scratch using:

* Convolution Layers
* Max Pooling Layers
* ReLU Activation
* Dropout Layers
* Fully Connected Dense Layers
* Softmax Output Layer
* Call Backs 

### 2. Transfer Learning – EfficientNetB0

To improve performance and feature extraction capability, EfficientNetB0 was used with pre-trained ImageNet weights.

Features:

* Pre-trained on ImageNet
* Fine-Tuning for Accident Classification
* Better Generalization
* Reduced Training Time
